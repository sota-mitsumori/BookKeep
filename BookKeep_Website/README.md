# Book Keep 公式ウェブサイト

Book Keepアプリの公式ウェブサイトです。

## ファイル構成

- `index.html` - メインのHTMLファイル
- `styles.css` - スタイルシート
- `README.md` - このファイル

## デプロイ方法

このウェブサイトは静的なHTMLファイルで構成されているため、任意のWebサーバーにアップロードして公開できます。

### GitHub Pagesでの公開例

1. このディレクトリをGitリポジトリとして初期化
2. GitHubにプッシュ
3. GitHubリポジトリのSettings > Pagesで公開

### その他のホスティングサービス

- Netlify
- Vercel
- Firebase Hosting
- AWS S3 + CloudFront

など、静的サイトホスティングサービスを利用できます。

## カスタマイズ

- `styles.css`で色やレイアウトを変更できます
- `index.html`でコンテンツを編集できます
- App Storeのバッジ画像（`app-store-badge.svg`）を追加する場合は、同じディレクトリに配置してください
